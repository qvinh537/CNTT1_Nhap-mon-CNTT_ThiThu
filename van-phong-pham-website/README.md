# Dự án Website Cửa hàng Văn phòng phẩm
Dự án phát triển hệ thống ***website bán lẻ văn phòng phẩm*** dành cho cửa hàng.
## Cấu trúc thư mục
| Thư mục | Nội dung |
| :--- | :--- |
| docs/ | Tài liệu quản lý nhập hàng và hướng dẫn nghiệp vụ |
| media/ | Chứa hình ảnh, logo và tài nguyên thiết kế |
| data/ | Dữ liệu bán hàng và thông tin sản phẩm (Excel) |
| logs/ | Nhật ký hoạt động và hệ thống báo cáo lỗi |
| backup/ | Bản sao lưu tài nguyên quan trọng |
